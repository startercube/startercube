# J Yong · 게임 기획 지망

규칙을 문서로 정리하고, Unity로 직접 만들어 보고, 플레이 테스트 결과에 따라 고칩니다.

## 🎯 대표 프로젝트

### 🧸 [꼭꼭방역](https://github.com/startercube/GgokGgok) — 1인칭 3D 숨바꼭질

> 🏆 2026 하계 오픈소스SW 해커톤 우수상(2위) · 2026 Hallym AI·SW Week 동아리 전시회 은상(2위)<br>
> 2인 개발 · Unity 6 (URP)

"보면 굳고, 눈을 떼면 움직이는" 외계 생물을 시선·웃음소리·얼룩 단서로 찾아내는 게임입니다.

- **맡은 일**: 게임 기획·설계 총괄(컨셉, 핵심 규칙, 승패 조건, 게임 흐름, 스테이지 테마, UI/UX)과 주요 시스템 구현
- **기획 의도**: 혼자서는 느끼기 어려운 숨바꼭질의 긴장감을, 시선에 반응하는 AI와 단서 추리로 1인 플레이에 옮겼습니다.
- **플레이 테스트로 고친 것**
  - 패배 조건을 '어질러진 것 25개'에서 '얼룩 11개(경고 7개)'로 조정해, 지기 전에 위기를 알 수 있게 했습니다.
  - 웃음소리가 시야 밖에서만 나도록 바꿔, 소리 자체가 "지금 안 보이는 곳에 있다"는 단서가 되게 했습니다. (공동 작업)
  - 처음 하는 사람도 바로 플레이하도록 선임 NPC가 안내하는 튜토리얼을 추가했습니다.

### 📦 [설치 할래 말래?](https://github.com/startercube/InstallOrNot) — 모바일 캐주얼 미니게임

> 2026-1 소프트웨어캡스톤디자인 · 3인 개발 · Unity 2022 (Android)

광고 팝업, 몰래 체크된 번들 설치 같은 나쁜 UI/UX를 '깨부수는 장애물'로 뒤집은 미니게임 모음입니다.

- **맡은 일**: 미니게임 기획, 게임 이름, '파일 수집' 미니게임 설계·구현, 발표 자료·포스터·결과 보고서
- **난이도 설계**: 기울기 조작 미니게임에서 진행률에 따라 스폰 간격을 1초에서 0.4초로 줄이고, 낙하 속도를 최대 3배까지 올렸습니다.
